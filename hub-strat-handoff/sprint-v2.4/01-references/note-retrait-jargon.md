## 8. Test de validation v2.4

Avant publication d'un livrable, Claude Design exécute le test suivant :

1. Recherche `Ctrl+F` ou équivalent dans le document pour chacun des termes listés §1 à §6
2. Si **une occurrence est trouvée**, le document n'est pas conforme — retour pour itération
3. Si **aucune occurrence**, lecture rapide pour vérifier l'absence de codification résiduelle non listée
