Template Étude de cas — guide d'usage

Ce fichier est un guide d'usage pour Claude Code. Voir le commentaire HTML en tête pour le pattern à suivre.

Pour produire un nouveau module CU étude de cas + checklist :

  1. Copier _template-auto-diagnostic.html comme base (le squelette HTML est identique).
  2. Remplacer le badge 📋 Auto-diagnostic par 📋 Étude de cas + checklist.
  3. Remplacer la section auto-diagnostic interactive par une checklist statique en .checklist-block (12-15 points d'éligibilité contractuels typiques).
  4. Retirer les fonctions JS evaluateAutoDiag() et exportAutoDiag() — non nécessaires pour une checklist statique.
  5. Ajouter une section « Étude de cas approfondie » avec .case-deep-actor (acteur, contexte, dispositif, résultats sourcés).
  6. Le reste suit RULES § 1.5.1 strictement (nav, hero, module-layout, executive-summary, sections numérotées, id="ressources" Schéma A, footer, script).

Référence canonique pour ce format : CU-016 Maintenance prédictive (cas Alfi Technologies + checklist 12 points typique).
