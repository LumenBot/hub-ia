👁️ Contrôle qualité par vision IA

Détection automatique de défauts à cadence industrielle : papier, panneaux bois, textile, agroalimentaire. Taux de détection 95-99 %, ROI 12-18 mois pour un ETI sur ligne moyenne.

Le cas

Le contrôle qualité humain a quatre limites structurelles : vitesse de cadence, fatigue, subjectivité, coût. Le contrôle par vision IA adresse ces quatre limites simultanément. Il augmente typiquement le contrôle humain en première ligne, plutôt que de le remplacer totalement, sauf sur des process de très grande série.

Sur le territoire vosgien, les filières concernées sont multiples : papier (Norske Skog, Lucart, Clairefontaine), panneaux bois (Egger, NS-Weisrock), textile (Innothera, Bleu Forêt), plasturgie (Reborn, PTP Industry), agroalimentaire (Ermitage, Lactalis Marcillat).

L'architecture

  1. Caméras industrielles placées en ligne ou hors ligne. Choix selon défaut : caméra couleur standard, hyperspectrale, caméra ligne (flux continus type bobines)
  2. Modèle de vision IA entraîné sur images de pièces conformes + images de défauts (toutes catégories)
  3. Inférence en ligne — chaque pièce analysée en temps réel. Verdict : OK / NOK + catégorie de défaut
  4. Action automatique — éjection, marquage, alerte opérateur, ralentissement ligne
  5. Boucle d'amélioration — pièces ambiguës validées par opérateur, enrichissement du dataset

Stack technique

  • Solutions du marché : Cognex VisionPro, Keyence, Landing AI, Neurala
  • Solutions françaises : Pollen Robotics, Wisecode
  • Cloud / pre-built : AWS Rekognition, Azure Computer Vision, Google Vision (cas génériques)
  • Custom open source : YOLO, MMDetection, PyTorch / TensorFlow (équipe data interne)
  • Hardware : caméras industrielles (Basler, IDS), éclairage technique, edge computing (NVIDIA Jetson)
  • Mistral Forge pour fine-tuner sur datasets propres à l'industriel

Indicateurs documentés

  • Taux de détection : 95-99 % typique pour des cas matures
  • Faux rejets : <1 % pour les systèmes bien calibrés
  • Cadence : 100 à 1 000 pièces/seconde possible
  • ROI : 12-18 mois pour un ETI sur ligne moyenne, 6-12 mois pour très grandes séries
  • Réduction du coût qualité : 30-50 % typique

Limites et points de vigilance

  • Volume initial d'images annotées — démarrer sans dataset est très difficile. Pour défauts rares, plusieurs mois de collecte initiale
  • Drift du process — quand le process évolue (matière, paramètres), modèle peut perdre en performance. Re-calibration nécessaire
  • Coût de mise en place — 30 à 200 K€ pour un système robuste, intégré et calibré
  • Compétences internes — partenaires territoriaux : Atsora Solutions, NIN-IA, intégrateurs spécialisés
  • AAP mobilisables : DECARB IND, Région Grand Est Compétitivité (jusqu'à 70 %), Pionniers IA
