Template Quiz — guide d'usage

Format quiz multi-choix réservé aux modules d'initiation (⭐ Niveau 1). Aucun module récent n'utilise ce format. Ce template est conservé pour usage éventuel futur.

Pour produire un nouveau module CU quiz :

  1. Copier _template-auto-diagnostic.html comme base (le squelette HTML est identique : nav 5 entrées, hero, module-layout, executive-summary, sections numérotées, id="ressources" Schéma A, footer, script).
  2. Remplacer le badge type par 📝 Quiz.
  3. Remplacer la section auto-diagnostic par une section quiz : <form> avec 5-10 questions à choix multiples, bouton « Vérifier mes réponses », correction immédiate (vert/rouge + explication).
  4. Adapter evaluateAutoDiag() en evaluateQuiz() — l'export téléchargeable n'est pas nécessaire pour un quiz pédagogique court.

Voir le commentaire HTML en tête de ce fichier pour les détails du pattern.
